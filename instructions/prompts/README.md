# Análise com Caido MCP

- `caido-analysis-instructions.txt`: cole como instrução do chat de Análise.
- `caido-analysis-starter.txt`: use para iniciar uma análise, preenchendo os campos entre colchetes.

Requer Caido MCP conectado. Forneça a política e o escopo do programa. Os prompts orientam a leitura do tráfego existente; envio e replay de requisições dependem de uma solicitação explícita.
